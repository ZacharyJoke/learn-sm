# 练习 04 绘制我的国密认知地图

## 目标

- 用 draw.io（diagrams.net）或纸笔，亲手产出一张个人国密认知地图。
- 把「五大原语、七大算法、典型场景、合规驱动」组织进同一张图的四个象限。
- 通过「脱稿复述」检验入门篇是否真正学懂，形成可长期复习的一张纸。

## 前置条件

- 已学习入门篇 6 篇文档，完成练习 01-03。
- 工具任选：draw.io 桌面版/网页版、Excalidraw、PPT，或 A4 纸 + 笔。

## 环境/路径

```bash
mkdir -p ~/gm-practice/04-map && cd ~/gm-practice/04-map
```

电子稿建议保存为 `~/gm-practice/04-map/国密认知地图.png`（或 `.drawio` / `.pdf`）；手绘稿拍照存到同目录。

## 详细步骤

### 步骤 1：划分四象限

在画布中央写主题「国密算法认知地图」，画出四个象限：

| 象限 | 标题 | 要放的内容 |
|------|------|-----------|
| 左上 | 五大原语 | 对称、非对称、杂凑、流密码、标识密码，各解决什么问题 |
| 右上 | 七大算法 | SM1、SM2、SM3、SM4、SM7、SM9、ZUC，类型 + 长度 + 是否公开 |
| 左下 | 典型场景 | 金融、政务、通信、物联网、身份认证、电子签章 |
| 右下 | 合规驱动 | 密码法、等保 2.0（GB 22239）、密评（GM/T 0054）、行业监管、自主可控 |

### 步骤 2：填入要素并画出连线

至少画出以下关键连接（体现「关系」而不只是罗列）：

- 原语 → 算法：如「非对称 → SM2」「杂凑 → SM3」「对称 → SM4/SM1/SM7」「流密码 → ZUC」「标识密码 → SM9」。
- 算法 → 场景：如「ZUC → 4G/5G 空口」「SM7 → 门禁/IC 卡」「SM2/SM3 → 电子签章」。
- 算法间依赖：SM2 签名内部使用 SM3；SM2 常保护 SM4 密钥（数字信封）。
- 驱动 → 场景：密评/等保/行业条款 → 金融、政务等改造。
- 标注公开程度：SM2/SM3/SM4/SM9/ZUC 公开，SM1/SM7 不公开。

### 步骤 3：脱稿复述并计时

合上所有资料，对着地图用 3 分钟讲完：

- 五大原语各解决什么问题；
- 七大算法各自定位与载体；
- 三个行业场景怎么用算法；
- 为什么要做国密改造。

用手机录音回听，卡壳处在地图上做标记，再针对性补记。

### 步骤 4：迭代修改

至少修改一版：补齐缺失要素、把连线关系画清楚、删除冗余文字，目标「别人看 30 秒能懂大意」。

## 扩展思考

1. 如果只能保留图上的三条主线，你会保留哪三个算法？为什么？
2. 如何用这张图向完全不懂密码的同事解释「为什么交易信息不会被篡改」？
3. 随着第二阶段原理学习深入，你打算给地图增加哪些「为什么安全」的标注？
4. SM1/SM7 不公开，在图上如何表达才能既准确又不让人误解为「更安全所以更高级」？

## 常见失败排查

- **只是一堆文字罗列、没有连线**：退回步骤 2，至少补齐「原语→算法→场景」「驱动→场景」两类关系线。
- **算法长度/标准号填错**：回看 04 篇定位表核对，SM2 为 256 bit 曲线，SM4 为 128 bit、32 轮，SM3 为 256 bit 输出。
- **把 SM1/SM7 载体画反**：SM1 → 密码芯片/密码卡（SDF），SM7 → 非接触 IC 卡/门禁/票务。
- **复述频繁卡壳**：不是图的问题就是理解缺口，在卡壳点回查对应文档并改图。
- **追求美观迟迟不产出**：先用纸笔 30 分钟出初稿，内容优先，美化放到最后。
