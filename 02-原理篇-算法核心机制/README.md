## 📚 核心概念速览

### 三大主线的结构对照

```mermaid
graph LR
    subgraph SM2["SM2（非对称）"]
        A1["私钥 d（整数）"] --> A2["公钥 P=dG（曲线点）"]
        A2 --> A3["签名/加密/交换"]
    end
    subgraph SM3["SM3（杂凑）"]
        B1["任意长消息"] --> B2["分组填充 512bit"]
        B2 --> B3["64 轮压缩"]
        B3 --> B4["256bit 摘要"]
    end
    subgraph SM4["SM4（对称）"]
        C1["128bit 明文"] --> C2["32 轮 Feistel"]
        C3["128bit 密钥"] --> C4["轮密钥 rk"]
        C4 --> C2
        C2 --> C5["128bit 密文"]
    end
```

### 关键参数速记

| 算法 | 密钥长度 | 分组/输出 | 轮数 | 安全强度（约） |
|------|---------|----------|------|--------------|
| SM2 | 256 位私钥 | — | — | 128 位 |
| SM3 | — | 256 位摘要 | 64（压缩） | 128 位（碰撞） |
| SM4 | 128 位 | 128 位分组 | 32 | 128 位 |

## 💡 学习提示

- **重流程轻推导**：能跟着数据走一遍，比死记数学证明更重要
- **画图驱动**：每学一个算法，合上书画一次流程图
- **对比国际同类**：SM4↔AES、SM3↔SHA-256，差异中见设计意图
- **不钻牛角尖**：SM9 配对数学只需理解输入输出与用途
