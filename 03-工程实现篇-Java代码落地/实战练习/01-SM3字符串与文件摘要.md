# 练习 01 · SM3 字符串与文件摘要

用 BouncyCastle 跑通人生第一个国密算法：SM3 密码杂凑（密码哈希），并用国家标准测试向量证明你的实现正确。

---

## 🎯 练习目标

- 学会在 Maven 工程中引入 BouncyCastle（以下简称 BC）并注册 `BC` Provider
- 用 `MessageDigest.getInstance("SM3", "BC")` 计算字符串 SM3 摘要
- 用国家标准公开测试向量（空串、`abc`）断言结果完全一致
- 学会对任意文件做**流式** SM3 摘要（不把整个文件读进内存）
- 建立一个观念：**先对标准向量，再谈业务使用**

```xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <groupId>com.example</groupId>
    <artifactId>gm-sm3-demo</artifactId>
    <version>1.0.0</version>

    <properties>
        <maven.compiler.release>17</maven.compiler.release>
        <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
        <!-- BC 版本属性：真实项目由父 pom / dependencyManagement 统一锁定 -->
        <bc.version>1.84</bc.version>
    </properties>

    <dependencies>
        <!-- 国密算法核心提供者：SM2/SM3/SM4 全在这个包里 -->
        <dependency>
            <groupId>org.bouncycastle</groupId>
            <artifactId>bcprov-jdk18on</artifactId>
            <version>${bc.version}</version>
        </dependency>
    </dependencies>
</project>
```

> `jdk18on` 中的「18」指兼容 JDK 1.8+，在 JDK 17/21 上同样可用，不要误以为只支持 JDK 1.8。

### 步骤 3：编写完整 Java 代码

文件路径：`~/gm-practices/gm-sm3-demo/src/main/java/com/example/gm/Sm3Demo.java`

```java
package com.example.gm;

import org.bouncycastle.jce.provider.BouncyCastleProvider;

import java.io.InputStream;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.security.MessageDigest;
import java.security.Security;
import java.util.HexFormat;

public class Sm3Demo {

    private static final HexFormat HEX = HexFormat.of();
    private static final int BUFFER_SIZE = 8192;

    // 国家标准公开测试向量
    private static final String VECTOR_EMPTY =
            "1ab21d8355cfa17f8e61194831e81a8f22bec8c728fefb747ed035eb5082aa2b";
    private static final String VECTOR_ABC =
            "66c7f0f462eeedd9d1f2d46bdc10e4e24167c4875cf2f7a2297da02b8f4ba8e0";

    public static void main(String[] args) throws Exception {
        // 注册 BouncyCastle 提供者，之后才能按名称 "BC" 取用国密算法
        Security.addProvider(new BouncyCastleProvider());

        checkStandardVectors();

        if (args.length >= 1) {
            String fileDigest = sha3File(Path.of(args[0]));
            System.out.println("SM3(" + args[0] + ") =");
            System.out.println(fileDigest);
        } else {
            System.out.println("未传入文件路径。用法: mvn exec:java "
                    + "-Dexec.mainClass=com.example.gm.Sm3Demo "
                    + "-Dexec.args=\"/path/to/file\"");
        }
    }

    /** 计算字符串的 SM3，对照标准向量断言。 */
    static void checkStandardVectors() throws Exception {
        MessageDigest sm3 = MessageDigest.getInstance("SM3", "BC");

        String empty = HEX.formatHex(sm3.digest("".getBytes(StandardCharsets.UTF_8)));
        assertVector("SM3(\"\")", empty, VECTOR_EMPTY);

        String abc = HEX.formatHex(sm3.digest("abc".getBytes(StandardCharsets.UTF_8)));
        assertVector("SM3(\"abc\")", abc, VECTOR_ABC);
    }

    /** 流式计算文件 SM3：内存占用恒定为一个 8KB 缓冲区，文件多大都不怕。 */
    static String sha3File(Path file) throws Exception {
        MessageDigest sm3 = MessageDigest.getInstance("SM3", "BC");
        try (InputStream in = Files.newInputStream(file)) {
            byte[] buffer = new byte[BUFFER_SIZE];
            int read;
            while ((read = in.read(buffer)) != -1) {
                sm3.update(buffer, 0, read);
            }
        }
        return HEX.formatHex(sm3.digest());
    }

    static void assertVector(String name, String actual, String expected) {
        if (!actual.equals(expected)) {
            throw new IllegalStateException(name + " 不匹配标准向量!\n实际: " + actual
                    + "\n期望: " + expected);
        }
        System.out.println("[PASS] " + name + " = " + actual);
    }
}
```

关键点说明：

- `MessageDigest` 对象有状态：每次 `digest()` 后会自动复位，可以继续复用。
- `HexFormat.of().formatHex(bytes)` 是 JDK 17+ 内置的 Hex 编码方式，无需再引第三方编码工具。
- 文件摘要用 `update()` 分块喂数据，最后一次 `digest()` 收尾，全程不加载整个文件。

## 🧯 常见失败与排查

| 现象 | 原因 | 解决 |
|------|------|------|
| `java.security.NoSuchAlgorithmException: SM3` | 没有注册 BC，或没传 `"BC"` provider 参数 | 确认调用了 `Security.addProvider(new BouncyCastleProvider())` 且写法为 `getInstance("SM3", "BC")` |
| `NoSuchProviderException: no such provider: BC` | BC 依赖未引入或没注册成功 | 检查 `pom.xml` 中 `bcprov-jdk18on`，执行 `mvn dependency:tree` 确认依赖存在 |
| 标准向量不匹配（抛 `IllegalStateException`） | 字符串编码错误（如误用 GBK），或多算了换行符 | 统一用 `StandardCharsets.UTF_8`；确认 `""` 真的是空串 |
| 中文路径/中文输出乱码 | 终端或编译编码不是 UTF-8 | pom 中设置 `project.build.sourceEncoding=UTF-8`，终端用 UTF-8 |
| `mvn exec:java` 报找不到插件 | 网络问题导致插件没下载 | 检查网络/镜像配置，重试一次 |
