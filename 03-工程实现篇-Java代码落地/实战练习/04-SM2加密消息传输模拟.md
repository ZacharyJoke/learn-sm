# 练习 04 · SM2 加密消息传输模拟

扮演两个角色——发送方 Sender 与接收方 Receiver，用「公钥加密、私钥解密」完成一次保密订单消息传输：接收方先把公钥文件分发出去，发送方拿到公钥加密，接收方用私钥解密。

---

## 🎯 练习目标

- 理解 SM2 非对称加密的方向：**对方公钥加密，己方私钥解密**
- 掌握 SM2 密钥的文件化交换（公钥 `04` 开头 Hex、私钥 32 字节 Hex）
- 用 `Cipher.getInstance("SM2", "BC")` 加密/解密，默认密文格式为 C1C3C2（GM/T 0009）
- 加密一条 JSON 订单消息并在接收方还原打印
- 建立边界意识：SM2 适合加密**短数据**；长消息必须走数字信封（SM4 加密正文 + SM2 包裹 SM4 密钥）

---

## 📋 前置条件

**知识准备**

- 公钥可以发给任何人；私钥永远不出接收方机器
- SM2 密文默认结构：`C1（椭圆曲线点，04 开头 65 字节）‖ C3（32 字节摘要）‖ C2（与明文等长）`
- Base64 只是把二进制密文变成文本，便于在文件/网络中传递
- SM2 一次加密明文长度有限且开销大，不适合直接加密大段正文

**环境准备**

- JDK 17+、Maven 3.8+，已完成练习 01～03

### 步骤 3：编写密钥编解码工具 `Sm2Keys.java`

文件路径：`~/gm-practices/gm-sm2-msg/src/main/java/com/example/gm/Sm2Keys.java`

```java
package com.example.gm;

import org.bouncycastle.jcajce.provider.asymmetric.ec.BCECPrivateKey;
import org.bouncycastle.jcajce.provider.asymmetric.ec.BCECPublicKey;
import org.bouncycastle.jce.ECNamedCurveTable;
import org.bouncycastle.jce.spec.ECNamedCurveParameterSpec;
import org.bouncycastle.jce.spec.ECPrivateKeySpec;
import org.bouncycastle.jce.spec.ECPublicKeySpec;
import org.bouncycastle.math.ec.ECPoint;

import java.math.BigInteger;
import java.security.KeyFactory;
import java.security.KeyPair;
import java.security.KeyPairGenerator;
import java.security.PrivateKey;
import java.security.PublicKey;
import java.security.SecureRandom;
import java.security.spec.ECGenParameterSpec;
import java.util.HexFormat;

final class Sm2Keys {

    static final HexFormat HEX = HexFormat.of();
    static final ECNamedCurveParameterSpec CURVE = ECNamedCurveTable.getParameterSpec("sm2p256v1");

    private Sm2Keys() {
    }

    static KeyPair generate() throws Exception {
        KeyPairGenerator keyPairGenerator = KeyPairGenerator.getInstance("EC", "BC");
        keyPairGenerator.initialize(new ECGenParameterSpec("sm2p256v1"), new SecureRandom());
        return keyPairGenerator.generateKeyPair();
    }

    static String encodePublic(PublicKey publicKey) {
        return HEX.formatHex(((BCECPublicKey) publicKey).getQ().getEncoded(false));
    }

    static String encodePrivate(PrivateKey privateKey) {
        byte[] d = ((BCECPrivateKey) privateKey).getD().toByteArray();
        byte[] d32 = new byte[32];
        System.arraycopy(d, Math.max(0, d.length - 32), d32,
                Math.max(0, 32 - d.length), Math.min(d.length, 32));
        return HEX.formatHex(d32);
    }

    static PublicKey decodePublic(String qHex) throws Exception {
        ECPoint point = CURVE.getCurve().decodePoint(HEX.parseHex(qHex));
        return KeyFactory.getInstance("EC", "BC")
                .generatePublic(new ECPublicKeySpec(point, CURVE));
    }

    static PrivateKey decodePrivate(String dHex) throws Exception {
        return KeyFactory.getInstance("EC", "BC")
                .generatePrivate(new ECPrivateKeySpec(new BigInteger(1, HEX.parseHex(dHex)), CURVE));
    }
}
```

> 私钥 D 转成 Hex 前要先规范为 32 字节：`BigInteger.toByteArray()` 可能返回 33 字节（首位补 0）或更短，直接 Hex 会导致长度漂移。

### 步骤 4：编写发送方 `Sender.java`

文件路径：`~/gm-practices/gm-sm2-msg/src/main/java/com/example/gm/Sender.java`

```java
package com.example.gm;

import org.bouncycastle.jce.provider.BouncyCastleProvider;

import javax.crypto.Cipher;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.security.PublicKey;
import java.security.SecureRandom;
import java.security.Security;
import java.util.Base64;

public class Sender {

    static final String ORDER_JSON =
            "{\"orderId\":\"A20260922001\",\"buyer\":\"张三\",\"amount\":100.00,\"currency\":\"CNY\"}";

    public static void main(String[] args) throws Exception {
        Security.addProvider(new BouncyCastleProvider());
        if (args.length != 1) {
            System.out.println("Usage: Sender <exchange-dir>");
            System.exit(1);
        }

        Path dir = Path.of(args[0]);
        Path publicKeyFile = dir.resolve("receiver-pub.key");
        String qHex = Files.readString(publicKeyFile, StandardCharsets.UTF_8).trim();
        PublicKey receiverPublicKey = Sm2Keys.decodePublic(qHex);

        Cipher cipher = Cipher.getInstance("SM2", "BC");
        cipher.init(Cipher.ENCRYPT_MODE, receiverPublicKey, new SecureRandom());
        byte[] cipherBytes = cipher.doFinal(ORDER_JSON.getBytes(StandardCharsets.UTF_8));

        Path messageFile = dir.resolve("message.dat");
        Files.writeString(messageFile, Base64.getEncoder().encodeToString(cipherBytes),
                StandardCharsets.UTF_8);

        System.out.println("发送方已用接收方公钥加密订单消息 -> " + messageFile);
    }
}
```

### 步骤 5：编写接收方 `Receiver.java`

文件路径：`~/gm-practices/gm-sm2-msg/src/main/java/com/example/gm/Receiver.java`

```java
package com.example.gm;

import org.bouncycastle.jce.provider.BouncyCastleProvider;

import javax.crypto.Cipher;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.attribute.PosixFilePermission;
import java.security.KeyPair;
import java.security.PrivateKey;
import java.security.Security;
import java.util.Base64;
import java.util.Set;

public class Receiver {

    public static void main(String[] args) throws Exception {
        Security.addProvider(new BouncyCastleProvider());
        if (args.length < 2) {
            usage();
            System.exit(1);
        }
        Path dir = Path.of(args[1]);

        switch (args[0]) {
            case "keygen" -> keygen(dir);
            case "decrypt" -> {
                if (args.length != 3) {
                    usage();
                    System.exit(1);
                }
                decrypt(dir, Path.of(args[2]));
            }
            default -> {
                usage();
                System.exit(1);
            }
        }
    }

    static void keygen(Path dir) throws Exception {
        Files.createDirectories(dir);
        KeyPair keyPair = Sm2Keys.generate();

        Path publicKeyFile = dir.resolve("receiver-pub.key");
        Path privateKeyFile = dir.resolve("receiver-priv.key");
        Files.writeString(publicKeyFile, Sm2Keys.encodePublic(keyPair.getPublic()),
                StandardCharsets.UTF_8);
        Files.writeString(privateKeyFile, Sm2Keys.encodePrivate(keyPair.getPrivate()),
                StandardCharsets.UTF_8);
        restrictToOwner(privateKeyFile);

        System.out.println("接收方密钥对已生成:");
        System.out.println("公钥文件（分发给发送方）: " + publicKeyFile);
        System.out.println("私钥文件（保密）       : " + privateKeyFile);
    }

    static void decrypt(Path dir, Path messageFile) throws Exception {
        Path privateKeyFile = dir.resolve("receiver-priv.key");
        String dHex = Files.readString(privateKeyFile, StandardCharsets.UTF_8).trim();
        PrivateKey privateKey = Sm2Keys.decodePrivate(dHex);

        String cipherBase64 = Files.readString(messageFile, StandardCharsets.UTF_8).trim();
        byte[] cipherBytes = Base64.getDecoder().decode(cipherBase64);

        Cipher cipher = Cipher.getInstance("SM2", "BC");
        cipher.init(Cipher.DECRYPT_MODE, privateKey);
        byte[] plainBytes = cipher.doFinal(cipherBytes);

        System.out.println("接收方解密成功，订单明文:");
        System.out.println(new String(plainBytes, StandardCharsets.UTF_8));
    }

    static void restrictToOwner(Path file) {
        try {
            Files.setPosixFilePermissions(file, Set.of(
                    PosixFilePermission.OWNER_READ, PosixFilePermission.OWNER_WRITE));
        } catch (UnsupportedOperationException | java.io.IOException e) {
            System.out.println("提示: 无法设置 POSIX 权限，请手工限制私钥文件访问: " + file);
        }
    }

    static void usage() {
        System.out.println("Usage: Receiver keygen <exchange-dir>");
        System.out.println("       Receiver decrypt <exchange-dir> <message.dat>");
    }
}
```

## 🧯 常见失败与排查

| 现象 | 原因 | 解决 |
|------|------|------|
| `NoSuchFileException: receiver-pub.key` | 没先跑 `Receiver keygen`，或交换目录路径不一致 | 先执行 keygen；确认 Sender/Receiver 用同一个目录 |
| 解密抛异常 / 得到乱码 | 密文格式不匹配（C1C2C3 与 C1C3C2 混用） | BC 默认 C1C3C2，双方保持默认；不要与旧系统裸拼接 |
| Hex 解析报错 | 密钥文件混入换行/空格 | 读取后 `trim()`；确认文件只含一行 Hex |
| 中文解密乱码 | 解密后未按 UTF-8 还原 | `new String(bytes, StandardCharsets.UTF_8)` |
| 私钥文件权限仍是 `rw-r--r--` | 文件系统不支持 POSIX（如某些外置盘） | 手工收紧权限；敏感密钥应放密钥库/KMS |
| 加密大文本失败或性能极差 | SM2 不适合长数据 | 改用数字信封（SM4 + SM2 包裹） |
