# 练习 06 · SM4 加密文件存储工具

做一个真正能落盘的文件加密工具：明文文件加密成带文件头的 `.enc`，数据密钥 DEK 单独存放为 `.key`；解密时读回头部、还原 DEK、解密恢复原文。核心是「带元数据的文件格式设计」与「数据与密钥分离」。

---

## 🎯 练习目标

- 每次加密随机生成一把 SM4 数据密钥 DEK（128 位），零硬编码
- 设计并实现带文件头的 `.enc` 格式：`magic / version / nonce / ciphertext / tag`
- DEK 与密文分离存放：`.key` 文件
- 支持两种 DEK 保护模式：SM2 公钥信封（推荐路径）与 Base64 占位（仅本地演示）
- 解密还原文件，并与原文件逐字节比对一致
- 理解为什么生产环境必须用 SM2 信封 / KMS，而不是明文存放 DEK

---

## 📋 前置条件

**知识准备**

- DEK（Data Encryption Key）：真正加密业务数据的对称密钥；每个文件一把、随机生成
- 密钥分离：密文与 DEK 分开存储，泄露其中一个不影响安全
- GCM nonce 12 字节、tag 16 字节；密文长度与明文相同（流加密）
- magic（魔数）与 version 用于识别文件类型与未来格式演进
- 数字信封：用接收方 SM2 公钥加密短 DEK，接收方用私钥解出 DEK

- JDK 17+、Maven 3.8+，已完成练习 02、04

### 步骤 3：设计 `.enc` 文件格式（字节布局）

文件总长度 = `17（头部）+ N（密文）+ 16（tag）`，其中 N 等于明文长度。

| 偏移 | 长度（字节） | 字段 | 内容/说明 |
|------|-------------|------|-----------|
| 0 | 4 | magic | ASCII `SM4G`（十六进制 `53 4D 34 47`），用于识别文件类型 |
| 4 | 1 | version | `0x01`，格式版本，便于以后演进 |
| 5 | 12 | nonce（IV） | GCM nonce，每次加密 `SecureRandom` 随机 |
| 17 | N | ciphertext | SM4-GCM 密文，与明文等长 |
| 17 + N | 16 | tag | GCM 认证标签，解密时自动校验 |

### 步骤 4：设计 `.key` 文件格式（DEK 分离存放）

| 前 4 字节 magic | 其余内容 | 含义 |
|-----------------|----------|------|
| `DK01` | Base64(DEK) | **仅本地演示**：DEK 未受保护，严禁用于生产 |
| `SM21` | Base64(SM2加密(DEK)) | **推荐**：用环境变量 `SM2_RECIPIENT_PUB` 指定接收方公钥做信封 |

> 说明：DEK 只有 16 字节，正是 SM2 最适合加密的短数据。生产环境由接收方用私钥（或 KMS）解包；本练习解密端支持用环境变量 `SM2_RECIPIENT_PRIVATE` 解包，仅为本地闭环演示。

### 步骤 5：编写完整 Java 代码

文件路径：`~/gm-practices/gm-file-enc/src/main/java/com/example/gm/FileEncTool.java`

```java
package com.example.gm;

import org.bouncycastle.jcajce.provider.asymmetric.ec.BCECPublicKey;
import org.bouncycastle.jce.ECNamedCurveTable;
import org.bouncycastle.jce.provider.BouncyCastleProvider;
import org.bouncycastle.jce.spec.ECNamedCurveParameterSpec;
import org.bouncycastle.jce.spec.ECPublicKeySpec;
import org.bouncycastle.math.ec.ECPoint;

import javax.crypto.Cipher;
import javax.crypto.KeyGenerator;
import javax.crypto.SecretKey;
import javax.crypto.spec.GCMParameterSpec;
import javax.crypto.spec.SecretKeySpec;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.security.KeyFactory;
import java.security.PrivateKey;
import java.security.PublicKey;
import java.security.SecureRandom;
import java.security.Security;
import java.util.Arrays;
import java.util.Base64;
import java.util.HexFormat;

public class FileEncTool {

    static final byte[] ENC_MAGIC = "SM4G".getBytes(StandardCharsets.US_ASCII);
    static final byte ENC_VERSION = 1;
    static final int NONCE_LEN = 12;
    static final int TAG_LEN = 16;

    static final byte[] DEK_MAGIC = "DK01".getBytes(StandardCharsets.US_ASCII);
    static final byte[] SM2_MAGIC = "SM21".getBytes(StandardCharsets.US_ASCII);

    public static void main(String[] args) throws Exception {
        Security.addProvider(new BouncyCastleProvider());
        if (args.length != 4 || (!args[0].equals("encrypt") && !args[0].equals("decrypt"))) {
            System.out.println("Usage: FileEncTool encrypt <in> <out.enc> <out.key>");
            System.out.println("       FileEncTool decrypt <in.enc> <in.key> <out>");
            System.exit(1);
        }
        if (args[0].equals("encrypt")) {
            encrypt(Path.of(args[1]), Path.of(args[2]), Path.of(args[3]));
        } else {
            decrypt(Path.of(args[1]), Path.of(args[2]), Path.of(args[3]));
        }
    }

    static void encrypt(Path in, Path encOut, Path keyOut) throws Exception {
        KeyGenerator keyGenerator = KeyGenerator.getInstance("SM4", "BC");
        keyGenerator.init(128);
        SecretKey dek = keyGenerator.generateKey();

        byte[] nonce = new byte[NONCE_LEN];
        new SecureRandom().nextBytes(nonce);

        Cipher cipher = Cipher.getInstance("SM4/GCM/NoPadding", "BC");
        cipher.init(Cipher.ENCRYPT_MODE, dek, new GCMParameterSpec(TAG_LEN * 8, nonce));
        byte[] sealed = cipher.doFinal(Files.readAllBytes(in));
        int cipherLength = sealed.length - TAG_LEN;

        try (java.io.OutputStream out = Files.newOutputStream(encOut)) {
            out.write(ENC_MAGIC);
            out.write(ENC_VERSION);
            out.write(nonce);
            out.write(sealed, 0, cipherLength);
            out.write(sealed, cipherLength, TAG_LEN);
        }

        String recipientPublicHex = System.getenv("SM2_RECIPIENT_PUB");
        if (recipientPublicHex != null && !recipientPublicHex.isBlank()) {
            Cipher sm2 = Cipher.getInstance("SM2", "BC");
            sm2.init(Cipher.ENCRYPT_MODE, parsePublicKey(recipientPublicHex.strip()), new SecureRandom());
            byte[] wrapped = sm2.doFinal(dek.getEncoded());
            Files.write(keyOut, concat(SM2_MAGIC, Base64.getEncoder().encode(wrapped)));
            System.out.println("DEK wrapped with SM2 public key -> " + keyOut);
        } else {
            Files.write(keyOut, concat(DEK_MAGIC, Base64.getEncoder().encode(dek.getEncoded())));
            System.out.println("WARNING: DEK stored as Base64 WITHOUT protection (" + keyOut
                    + "). Local demo only; production must set SM2_RECIPIENT_PUB or use KMS.");
        }
        System.out.println("Encrypted " + in + " -> " + encOut);
    }

    static void decrypt(Path encIn, Path keyIn, Path out) throws Exception {
        byte[] enc = Files.readAllBytes(encIn);
        checkMagic(enc, ENC_MAGIC);
        if (enc[4] != ENC_VERSION) {
            throw new IllegalStateException("unsupported version: " + enc[4]);
        }
        byte[] nonce = Arrays.copyOfRange(enc, 5, 5 + NONCE_LEN);
        byte[] sealed = Arrays.copyOfRange(enc, 5 + NONCE_LEN, enc.length);

        byte[] keyFile = Files.readAllBytes(keyIn);
        byte[] dekBytes;
        if (startsWith(keyFile, SM2_MAGIC)) {
            String privateHex = System.getenv("SM2_RECIPIENT_PRIVATE");
            if (privateHex == null || privateHex.isBlank()) {
                throw new IllegalStateException(
                        "SM2-wrapped key detected but SM2_RECIPIENT_PRIVATE not set");
            }
            byte[] wrapped = Base64.getDecoder().decode(
                    Arrays.copyOfRange(keyFile, 4, keyFile.length));
            Cipher sm2 = Cipher.getInstance("SM2", "BC");
            sm2.init(Cipher.DECRYPT_MODE, parsePrivateKey(privateHex.strip()));
            dekBytes = sm2.doFinal(wrapped);
        } else if (startsWith(keyFile, DEK_MAGIC)) {
            dekBytes = Base64.getDecoder().decode(
                    Arrays.copyOfRange(keyFile, 4, keyFile.length));
        } else {
            throw new IllegalStateException("unknown key file format");
        }

        Cipher cipher = Cipher.getInstance("SM4/GCM/NoPadding", "BC");
        cipher.init(Cipher.DECRYPT_MODE, new SecretKeySpec(dekBytes, "SM4"),
                new GCMParameterSpec(TAG_LEN * 8, nonce));
        byte[] plain = cipher.doFinal(sealed);
        Files.write(out, plain);
        System.out.println("Decrypted " + encIn + " -> " + out);
    }

    static PrivateKey parsePrivateKey(String dHex) throws Exception {
        ECNamedCurveParameterSpec spec = ECNamedCurveTable.getParameterSpec("sm2p256v1");
        return KeyFactory.getInstance("EC", "BC").generatePrivate(
                new org.bouncycastle.jce.spec.ECPrivateKeySpec(
                        new java.math.BigInteger(1, HexFormat.of().parseHex(dHex)), spec));
    }

    static PublicKey parsePublicKey(String qHex) throws Exception {
        ECNamedCurveParameterSpec spec = ECNamedCurveTable.getParameterSpec("sm2p256v1");
        ECPoint point = spec.getCurve().decodePoint(HexFormat.of().parseHex(qHex));
        return KeyFactory.getInstance("EC", "BC")
                .generatePublic(new ECPublicKeySpec(point, spec));
    }

    static byte[] concat(byte[] a, byte[] b) {
        byte[] result = new byte[a.length + b.length];
        System.arraycopy(a, 0, result, 0, a.length);
        System.arraycopy(b, 0, result, a.length, b.length);
        return result;
    }

    static void checkMagic(byte[] data, byte[] magic) {
        if (!startsWith(data, magic)) {
            throw new IllegalStateException("bad magic, not a valid file");
        }
    }

    static boolean startsWith(byte[] data, byte[] prefix) {
        if (data.length < prefix.length) {
            return false;
        }
        for (int i = 0; i < prefix.length; i++) {
            if (data[i] != prefix[i]) {
                return false;
            }
        }
        return true;
    }
}
```

## 🧯 常见失败与排查

| 现象 | 原因 | 解决 |
|------|------|------|
| `IllegalStateException: bad magic` | 输入不是本工具生成的 `.enc`，或参数顺序填错 | 确认用法 `encrypt/decrypt <in> <enc> <key>` |
| `unsupported version` | 文件来自更高版本工具 | 使用匹配版本，或在代码中做兼容 |
| `AEADBadTagException: mac check in GCM failed` | 密文/nonce 被改，或 DEK 不匹配 | 使用原 `.key`；确认未篡改文件 |
| `SM2-wrapped key detected but SM2_RECIPIENT_PRIVATE not set` | 解密信封文件但没提供私钥 | 设置 `SM2_RECIPIENT_PRIVATE`；生产走 KMS 解包 |
| `InvalidKeyException` | DEK 长度不是 16 字节 | 不要手工编辑 `.key`；重新加密 |
| 解密后字节数对不上 | 拆段偏移错误 | 严格按布局表：nonce 在 5..17，其余为 sealed |
| Base64 解码异常 | `.key` 复制时混入换行/空格 | 完整复制，`trim()` 仅用于 Hex 输入 |

> API 版本提示：SM2 信封相关构造基于 bcprov-jdk18on 1.84 实测；升级时以该版 Javadoc 为准。生产环境的私钥解包应在 KMS/HSM 内完成，不要把私钥放到普通环境变量。
