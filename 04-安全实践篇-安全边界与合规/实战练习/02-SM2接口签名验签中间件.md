# 练习 02 SM2 接口签名验签中间件

> 给 Spring Boot 做一个注解驱动的接口签名中间件，一次具备防篡改、防重放、防抵赖，并用 MockMvc 跑通三类负向用例。

## 目标

- 自定义 `@SignedMapping` 注解，标注需要签名校验的接口。
- 用 `HandlerInterceptor` 校验请求头 `X-App-Id / X-Timestamp / X-Nonce / X-Signature`。
- 签名原文：`appId\ntimestamp\nnonce\nmethod\npath\nSM3(body)Hex`；SM2 默认用户 ID `1234567812345678`，密文 / 签名编码约定明确。
- nonce 去重提供内存实现（测试用）与 Redis 实现（生产多实例用）。
- MockMvc 覆盖：正常通过、时间过期、重放、错签。

## 前置

- JDK 17+、Maven；Spring Boot 3.3.x（版本可替换为更新稳定版）。
- 应用私钥 / 伙伴公钥从环境变量、KMS 或配置引用加载，**代码与 yml 中不出现密钥明文**。

### 2. 应用公钥注册中心

`AppCredentialStore.java`：

```java
package com.example.sign;

import org.bouncycastle.crypto.params.ECPublicKeyParameters;
import org.springframework.stereotype.Component;

import java.util.Map;
import java.util.Optional;
import java.util.concurrent.ConcurrentHashMap;

@Component
public class AppCredentialStore {

    private final Map<String, ECPublicKeyParameters> credentials = new ConcurrentHashMap<>();

    public void register(String appId, ECPublicKeyParameters publicKey) {
        credentials.put(appId, publicKey);
    }

    public Optional<ECPublicKeyParameters> find(String appId) {
        return Optional.ofNullable(credentials.get(appId));
    }
}
```

生产用法：写一个初始化器，从环境变量指定的来源（KMS、证书文件路径、配置中心里的公钥引用）取公钥后 `register`；不要把公钥明文写进 yml，私钥更不能出现在应用侧。

`InMemoryNonceStore.java`：

```java
package com.example.sign;

import org.springframework.boot.autoconfigure.condition.ConditionalOnMissingBean;
import org.springframework.stereotype.Component;

import java.util.concurrent.ConcurrentHashMap;

@Component
@ConditionalOnMissingBean(name = "redisNonceStore")
public class InMemoryNonceStore implements NonceStore {

    private final ConcurrentHashMap<String, Long> seen = new ConcurrentHashMap<>();

    @Override
    public boolean checkAndConsume(String appId, String nonce, long ttlMillis) {
        long now = System.currentTimeMillis();
        String key = appId + ":" + nonce;
        Long previous = seen.putIfAbsent(key, now + ttlMillis);
        if (previous != null && previous > now) {
            return false;
        }
        if (previous != null) {
            seen.replace(key, previous, now + ttlMillis);
        }
        cleanupIfLarge(now);
        return true;
    }

    private void cleanupIfLarge(long now) {
        if (seen.size() < 10_000) {
            return;
        }
        seen.entrySet().removeIf(entry -> entry.getValue() <= now);
    }
}
```

`RedisNonceStore.java`（多实例生产环境，按需启用）：

```java
package com.example.sign;

import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.stereotype.Component;

import java.time.Duration;

@Component("redisNonceStore")
public class RedisNonceStore implements NonceStore {

    private final StringRedisTemplate redis;

    public RedisNonceStore(StringRedisTemplate redis) {
        this.redis = redis;
    }

    @Override
    public boolean checkAndConsume(String appId, String nonce, long ttlMillis) {
        Boolean inserted = redis.opsForValue().setIfAbsent(
                "gm:nonce:" + appId + ":" + nonce, "1", Duration.ofMillis(ttlMillis));
        return Boolean.TRUE.equals(inserted);
    }
}
```

### 4. 签名与验签

`SignatureService.java`：

```java
package com.example.sign;

import org.bouncycastle.crypto.digests.SM3Digest;
import org.bouncycastle.crypto.params.ECPrivateKeyParameters;
import org.bouncycastle.crypto.params.ECPublicKeyParameters;
import org.bouncycastle.crypto.params.ParametersWithID;
import org.bouncycastle.crypto.params.ParametersWithRandom;
import org.bouncycastle.crypto.signers.SM2Signer;

import java.nio.charset.StandardCharsets;
import java.security.SecureRandom;
import java.util.Base64;

public class SignatureService {

    public static final String DEFAULT_USER_ID = "1234567812345678";
    private static final byte[] DEFAULT_ID_BYTES = DEFAULT_USER_ID.getBytes(StandardCharsets.UTF_8);

    private final SecureRandom random = new SecureRandom();

    public String sign(String appId, String timestamp, String nonce,
                       String method, String path, byte[] body,
                       ECPrivateKeyParameters privateKey) {
        byte[] content = buildContent(appId, timestamp, nonce, method, path, body);
        SM2Signer signer = new SM2Signer();
        signer.init(true, new ParametersWithID(
                new ParametersWithRandom(privateKey, random), DEFAULT_ID_BYTES));
        signer.update(content, 0, content.length);
        try {
            return Base64.getEncoder().encodeToString(signer.generateSignature());
        } catch (org.bouncycastle.crypto.CryptoException e) {
            throw new IllegalStateException("SM2 sign failed", e);
        }
    }

    public boolean verify(String appId, String timestamp, String nonce,
                          String method, String path, byte[] body,
                          String signature, ECPublicKeyParameters publicKey) {
        byte[] content = buildContent(appId, timestamp, nonce, method, path, body);
        SM2Signer signer = new SM2Signer();
        signer.init(false, new ParametersWithID(publicKey, DEFAULT_ID_BYTES));
        signer.update(content, 0, content.length);
        return signer.verifySignature(Base64.getDecoder().decode(signature));
    }

    public static byte[] buildContent(String appId, String timestamp, String nonce,
                                      String method, String path, byte[] body) {
        String bodyHash = Hex.encode(sm3(body));
        String raw = String.join("\n", appId, timestamp, nonce, method, path, bodyHash);
        return raw.getBytes(StandardCharsets.UTF_8);
    }

    private static byte[] sm3(byte[] input) {
        SM3Digest digest = new SM3Digest();
        digest.update(input, 0, input.length);
        byte[] hash = new byte[digest.getDigestSize()];
        digest.doFinal(hash, 0);
        return hash;
    }
}
```

```java
package com.example.sign;

public final class Hex {
    private static final char[] HEX = "0123456789abcdef".toCharArray();

    private Hex() {
    }

    public static String encode(byte[] bytes) {
        char[] out = new char[bytes.length * 2];
        for (int i = 0; i < bytes.length; i++) {
            out[i * 2] = HEX[(bytes[i] >> 4) & 0x0F];
            out[i * 2 + 1] = HEX[bytes[i] & 0x0F];
        }
        return new String(out);
    }
}
```

```java
package com.example.sign;

import jakarta.servlet.FilterChain;
import jakarta.servlet.ReadListener;
import jakarta.servlet.ServletInputStream;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletRequestWrapper;
import org.springframework.core.Ordered;
import org.springframework.core.annotation.Order;
import org.springframework.stereotype.Component;
import org.springframework.web.filter.OncePerRequestFilter;

import java.io.BufferedReader;
import java.io.ByteArrayInputStream;
import java.io.IOException;
import java.io.InputStreamReader;
import java.nio.charset.StandardCharsets;

@Component
@Order(Ordered.HIGHEST_PRECEDENCE)
public class CachedBodyFilter extends OncePerRequestFilter {

    @Override
    protected void doFilterInternal(jakarta.servlet.http.HttpServletRequest request,
                                    jakarta.servlet.http.HttpServletResponse response,
                                    FilterChain filterChain) throws java.io.IOException, jakarta.servlet.ServletException {
        filterChain.doFilter(new CachedBodyHttpServletRequest(request), response);
    }

    static final class CachedBodyHttpServletRequest extends HttpServletRequestWrapper {

        private final byte[] body;

        CachedBodyHttpServletRequest(HttpServletRequest request) throws IOException {
            super(request);
            this.body = request.getInputStream().readAllBytes();
        }

        @Override
        public ServletInputStream getInputStream() {
            ByteArrayInputStream input = new ByteArrayInputStream(body);
            return new ServletInputStream() {
                @Override
                public boolean isFinished() {
                    return input.available() == 0;
                }

                @Override
                public boolean isReady() {
                    return true;
                }

                @Override
                public void setReadListener(ReadListener readListener) {
                    throw new UnsupportedOperationException();
                }

                @Override
                public int read() {
                    return input.read();
                }
            };
        }

        @Override
        public BufferedReader getReader() {
            return new BufferedReader(new InputStreamReader(getInputStream(), StandardCharsets.UTF_8));
        }
    }
}
```

### 6. 拦截器

`SignatureInterceptor.java`：

```java
package com.example.sign;

import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import org.bouncycastle.crypto.params.ECPublicKeyParameters;
import org.springframework.stereotype.Component;
import org.springframework.web.method.HandlerMethod;
import org.springframework.web.servlet.HandlerInterceptor;

@Component
public class SignatureInterceptor implements HandlerInterceptor {

    private static final long ALLOWED_SKEW_MILLIS = 5 * 60 * 1000L;

    private final AppCredentialStore credentialStore;
    private final NonceStore nonceStore;
    private final SignatureService signatureService = new SignatureService();

    public SignatureInterceptor(AppCredentialStore credentialStore, NonceStore nonceStore) {
        this.credentialStore = credentialStore;
        this.nonceStore = nonceStore;
    }

    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler)
            throws Exception {
        if (!(handler instanceof HandlerMethod handlerMethod)) {
            return true;
        }
        SignedMapping signed = handlerMethod.getMethodAnnotation(SignedMapping.class);
        if (signed == null) {
            signed = handlerMethod.getBeanType().getAnnotation(SignedMapping.class);
        }
        if (signed == null) {
            return true;
        }

        String appId = request.getHeader("X-App-Id");
        String timestamp = request.getHeader("X-Timestamp");
        String nonce = request.getHeader("X-Nonce");
        String signature = request.getHeader("X-Signature");
        if (appId == null || timestamp == null || nonce == null || signature == null) {
            return reject(response, "MISSING_HEADERS");
        }

        long requestTime;
        try {
            requestTime = Long.parseLong(timestamp);
        } catch (NumberFormatException e) {
            return reject(response, "BAD_TIMESTAMP");
        }
        if (Math.abs(System.currentTimeMillis() - requestTime) > ALLOWED_SKEW_MILLIS) {
            return reject(response, "EXPIRED");
        }

        if (!nonceStore.checkAndConsume(appId, nonce, ALLOWED_SKEW_MILLIS)) {
            return reject(response, "REPLAY");
        }

        ECPublicKeyParameters publicKey = credentialStore.find(appId)
                .orElseThrow(() -> new SignatureException("UNKNOWN_APP", "unknown appId: " + appId));

        byte[] body = request.getInputStream().readAllBytes();
        boolean valid = signatureService.verify(appId, timestamp, nonce,
                request.getMethod(), request.getRequestURI(), body, signature, publicKey);
        if (!valid) {
            return reject(response, "BAD_SIGNATURE");
        }
        return true;
    }

    private boolean reject(HttpServletResponse response, String code) throws java.io.IOException {
        response.sendError(HttpServletResponse.SC_UNAUTHORIZED, code);
        return false;
    }
}
```

### 8. MockMvc 测试

`SignatureInterceptorTest.java`：

```java
package com.example.sign;

import org.bouncycastle.crypto.AsymmetricCipherKeyPair;
import org.bouncycastle.crypto.ec.CustomNamedCurves;
import org.bouncycastle.crypto.generators.ECKeyPairGenerator;
import org.bouncycastle.crypto.params.ECDomainParameters;
import org.bouncycastle.crypto.params.ECKeyGenerationParameters;
import org.bouncycastle.crypto.params.ECPrivateKeyParameters;
import org.bouncycastle.crypto.params.ECPublicKeyParameters;
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.autoconfigure.web.servlet.AutoConfigureMockMvc;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.http.MediaType;
import org.springframework.test.web.servlet.MockMvc;
import org.springframework.test.web.servlet.MvcResult;
import org.springframework.test.web.servlet.request.MockHttpServletRequestBuilder;

import java.security.SecureRandom;

import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.post;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.content;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.status;

@SpringBootTest
@AutoConfigureMockMvc
class SignatureInterceptorTest {

    private static final String APP_ID = "demo-app";
    private static final String PATH = "/api/orders";

    @Autowired
    private MockMvc mockMvc;

    @Autowired
    private AppCredentialStore credentialStore;

    private SignatureService signatureService;
    private ECPrivateKeyParameters privateKey;

    @BeforeEach
    void setUp() {
        ECDomainParameters domain = sm2Domain();
        ECKeyPairGenerator generator = new ECKeyPairGenerator();
        generator.init(new ECKeyGenerationParameters(domain, new SecureRandom()));
        AsymmetricCipherKeyPair pair = generator.generateKeyPair();
        credentialStore.register(APP_ID, (ECPublicKeyParameters) pair.getPublic());
        privateKey = (ECPrivateKeyParameters) pair.getPrivate();
        signatureService = new SignatureService();
    }

    @Test
    void validRequestPasses() throws Exception {
        String body = "{\"orderId\":\"A-1001\"}";
        String nonce = "nonce-valid-001";
        MockHttpServletRequestBuilder request = signedRequest(body, nonce, System.currentTimeMillis());
        mockMvc.perform(request)
                .andExpect(status().isOk())
                .andExpect(content().json("{\"accepted\":true,\"orderId\":\"A-1001\"}"));
    }

    @Test
    void expiredTimestampRejected() throws Exception {
        String body = "{\"orderId\":\"A-1002\"}";
        long oldTime = System.currentTimeMillis() - 10 * 60 * 1000L;
        MockHttpServletRequestBuilder request = signedRequest(body, "nonce-expired", oldTime);
        MvcResult result = mockMvc.perform(request)
                .andExpect(status().isUnauthorized())
                .andReturn();
        org.junit.jupiter.api.Assertions.assertTrue(result.getResponse().getErrorMessage().contains("EXPIRED"));
    }

    @Test
    void replayRejected() throws Exception {
        String body = "{\"orderId\":\"A-1003\"}";
        String nonce = "nonce-replay-fixed";
        MockHttpServletRequestBuilder first = signedRequest(body, nonce, System.currentTimeMillis());
        MockHttpServletRequestBuilder second = signedRequest(body, nonce, System.currentTimeMillis());
        mockMvc.perform(first).andExpect(status().isOk());
        MvcResult result = mockMvc.perform(second)
                .andExpect(status().isUnauthorized())
                .andReturn();
        org.junit.jupiter.api.Assertions.assertTrue(result.getResponse().getErrorMessage().contains("REPLAY"));
    }

    @Test
    void badSignatureRejected() throws Exception {
        String body = "{\"orderId\":\"A-1004\"}";
        MockHttpServletRequestBuilder request = signedRequest(body, "nonce-badsign", System.currentTimeMillis());
        request.content("{\"orderId\":\"A-1004-CHANGED\"}");
        MvcResult result = mockMvc.perform(request)
                .andExpect(status().isUnauthorized())
                .andReturn();
        org.junit.jupiter.api.Assertions.assertTrue(result.getResponse().getErrorMessage().contains("BAD_SIGNATURE"));
    }

    private MockHttpServletRequestBuilder signedRequest(String body, String nonce, long timestamp) {
        String signature = signatureService.sign(APP_ID, String.valueOf(timestamp), nonce,
                "POST", PATH, body.getBytes(java.nio.charset.StandardCharsets.UTF_8), privateKey);
        return post(PATH)
                .contentType(MediaType.APPLICATION_JSON)
                .header("X-App-Id", APP_ID)
                .header("X-Timestamp", timestamp)
                .header("X-Nonce", nonce)
                .header("X-Signature", signature)
                .content(body);
    }

    private static ECDomainParameters sm2Domain() {
        var parameters = CustomNamedCurves.getByName("sm2p256v1");
        return new ECDomainParameters(parameters.getCurve(), parameters.getG(),
                parameters.getN(), parameters.getH());
    }
}
```

## 验收标准

- 合法签名请求返回 200，业务响应正确。
- 时间戳超出 5 分钟窗口返回 401 且错误码为 `EXPIRED`。
- 同一 `appId + nonce` 第二次请求返回 401 `REPLAY`。
- body 与签名不一致返回 401 `BAD_SIGNATURE`。
- 未加 `@SignedMapping` 的 `/api/ping` 不受影响。
- 代码与配置中无密钥明文；签名使用 SM2 默认 ID，签名编码为 Base64。

## 扩展思考

- 当前签名只覆盖 path；若接口依赖 query string，应将 query（canonical 排序后）纳入原文。
- 多实例部署必须把 `InMemoryNonceStore` 换成 Redis 等共享存储，利用原子 `SET NX EX` 防并发绕过。
- 公钥应来自证书：校验证书链后取 SM2 公钥，而不是裸注册公钥，否则公钥被替换即变 MITM。
- 高敏操作建议叠加业务幂等键（如订单号唯一约束），nonce 只保证协议层不重放。
- 时间窗口依赖时钟同步，服务节点应统一 NTP。

## 失败排查

| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 所有请求 401 `BAD_SIGNATURE` | path / method 不一致 | 客户端签 `request.getRequestURI()`，与服务端严格一致；注意 contextPath |
| body 进 Controller 为空 | 请求体被 Filter 消费后不可重读 | 确认 `CachedBodyFilter` 已生效并最先执行 |
| 测试报端口 / 上下文冲突 | 复用工程 | MockMvc 不占端口；检查 application.yml |
| 第二、三个测试互相影响 | nonce 重复 | 每个用例使用不同 nonce；`@BeforeEach` 重新注册 |
| `ParametersWithID` 找不到 | BC 版本过老 | 升级 `bcprov-jdk18on` |
| 验签双方默认 ID 不一致 | 一方改了 ID | 统一 `1234567812345678` 或显式传参约定 |
