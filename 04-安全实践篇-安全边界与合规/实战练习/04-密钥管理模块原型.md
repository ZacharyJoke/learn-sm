# 练习 04 密钥管理模块原型

> 实现一个版本化的密钥服务：密钥带状态、密文带版本可路由旧密钥，轮换可平滑、泄露可吊销、全程审计追加写。

## 目标

- 定义 `KeyVersion`：`id / keyId / algorithm / state / createdAt`。
- 实现 `KeyService`：`create / activate / rotate / revoke`（含 `archive / destroy` 思路）。
- 密钥材料通过 `KeyMaterialStore` 接口存取，给出 PKCS#12 实现与 KMS 占位实现；口令从环境变量读取，零硬编码。
- 密文带 `keyVersionId`，解密路由到对应版本；轮换后旧密文仍可解，吊销后立即不可用。
- 轮换演练测试 + 审计日志追加写验证。

## 前置

- JDK 17+、Maven；BC 1.78（提供 SM4-GCM JCE）。
- PKCS#12 口令通过环境变量 `KM_KEYSTORE_PASSWORD` 注入；审计日志路径通过 `KM_AUDIT_LOG` 注入。

### 2. 密钥材料存储

`KeyMaterialStore.java`：

```java

    void save(String versionId, byte[] material);

    byte[] load(String versionId);

    void delete(String versionId);
}
```

设计说明：PKCS#12 标准只支持私钥（PrivateKey）条目，**不能直接存放 SM4 对称密钥**。因此本实现把 SM2 密钥对作为 KEK 存入 PKCS#12（首次使用时生成，并附一张自签 SM2 证书），SM4 DEK 则由 SM2 公钥做信封、以文件形式落在 `material/` 目录；每次取用时从 PKCS#12 现取私钥解开。这正对应「KEK 包 DEK」的分层实践。

`Pkcs12KeyMaterialStore.java`：

```java
package com.example.km;

import org.bouncycastle.crypto.InvalidCipherTextException;
import org.bouncycastle.crypto.engines.SM2Engine;
import org.bouncycastle.crypto.params.ECDomainParameters;
import org.bouncycastle.crypto.params.ECPrivateKeyParameters;
import org.bouncycastle.crypto.params.ECPublicKeyParameters;
import org.bouncycastle.crypto.params.ParametersWithRandom;
import org.bouncycastle.cert.jcajce.JcaX509v3CertificateBuilder;
import org.bouncycastle.asn1.x500.X500Name;
import org.bouncycastle.cert.jcajce.JcaX509CertificateConverter;
import org.bouncycastle.jce.provider.BouncyCastleProvider;
import org.bouncycastle.operator.ContentSigner;
import org.bouncycastle.operator.jcajce.JcaContentSignerBuilder;

import java.io.FileInputStream;
import java.io.FileOutputStream;
import java.math.BigInteger;
import java.nio.file.Files;
import java.nio.file.Path;
import java.security.KeyPair;
import java.security.KeyPairGenerator;
import java.security.KeyStore;
import java.security.SecureRandom;
import java.security.Security;
import java.security.cert.X509Certificate;
import java.security.spec.ECGenParameterSpec;
import java.util.Base64;
import java.util.Date;

public class Pkcs12KeyMaterialStore implements KeyMaterialStore {

    static {
        Security.addProvider(new BouncyCastleProvider());
    }

    private static final String KEK_ALIAS = "kek";
    private static final ECDomainParameters SM2_DOMAIN = sm2Domain();

    private final Path keyStoreFile;
    private final Path materialDir;
    private char[] password;
    private final SecureRandom random = new SecureRandom();

    public Pkcs12KeyMaterialStore(Path keyStoreFile, char[] password) {
        this.keyStoreFile = keyStoreFile;
        this.materialDir = keyStoreFile.resolveSibling("material");
        this.password = password.clone();
    }

    @Override
    public synchronized void save(String versionId, byte[] material) {
        ensureInitialized();
        ECPublicKeyParameters kekPublic = derivePublic(loadKekPrivateKey());
        SM2Engine sm2 = new SM2Engine(SM2Engine.Mode.C1C3C2);
        sm2.init(true, new ParametersWithRandom(kekPublic, random));
        try {
            byte[] wrapped = sm2.processBlock(material, 0, material.length);
            Files.createDirectories(materialDir);
            Files.writeString(materialDir.resolve(versionId + ".b64"),
                    Base64.getEncoder().encodeToString(wrapped));
        } catch (InvalidCipherTextException | java.io.IOException e) {
            throw new KeyStateException("MATERIAL_SAVE_FAILED", "version: " + versionId, e);
        }
    }

    @Override
    public synchronized byte[] load(String versionId) {
        Path file = materialDir.resolve(versionId + ".b64");
        if (!Files.exists(file)) {
            throw new KeyStateException("MATERIAL_NOT_FOUND", "version: " + versionId);
        }
        try {
            byte[] wrapped = Base64.getDecoder().decode(Files.readString(file));
            SM2Engine sm2 = new SM2Engine(SM2Engine.Mode.C1C3C2);
            sm2.init(false, loadKekPrivateKey());
            return sm2.processBlock(wrapped, 0, wrapped.length);
        } catch (InvalidCipherTextException | java.io.IOException e) {
            throw new KeyStateException("MATERIAL_LOAD_FAILED", "version: " + versionId, e);
        }
    }

    @Override
    public synchronized void delete(String versionId) {
        try {
            Files.deleteIfExists(materialDir.resolve(versionId + ".b64"));
        } catch (java.io.IOException e) {
            throw new KeyStateException("MATERIAL_DELETE_FAILED", "version: " + versionId, e);
        }
    }

    private void ensureInitialized() {
        if (Files.exists(keyStoreFile)) {
            return;
        }
        try {
            KeyPairGenerator generator = KeyPairGenerator.getInstance("EC", "BC");
            generator.initialize(new ECGenParameterSpec("sm2p256v1"), random);
            KeyPair keyPair = generator.generateKeyPair();

            long now = System.currentTimeMillis();
            X500Name subjectName = new X500Name("CN=gm-kek");
            JcaX509v3CertificateBuilder builder = new JcaX509v3CertificateBuilder(
                    subjectName,
                    BigInteger.ONE,
                    new Date(now),
                    new Date(now + 3650L * 24 * 60 * 60 * 1000),
                    subjectName,
                    keyPair.getPublic());
            ContentSigner signer = new JcaContentSignerBuilder("SM3withSM2")
                    .setProvider("BC").build(keyPair.getPrivate());
            X509Certificate certificate = new JcaX509CertificateConverter()
                    .setProvider("BC").getCertificate(builder.build(signer));

            Files.createDirectories(keyStoreFile.getParent());
            KeyStore keyStore = KeyStore.getInstance("PKCS12", "BC");
            keyStore.load(null, password);
            keyStore.setEntry(KEK_ALIAS,
                    new KeyStore.PrivateKeyEntry(keyPair.getPrivate(),
                            new X509Certificate[]{certificate}),
                    new KeyStore.PasswordProtection(password));
            try (FileOutputStream output = new FileOutputStream(keyStoreFile.toFile())) {
                keyStore.store(output, password);
            }
        } catch (Exception e) {
            throw new KeyStateException("KEK_INIT_FAILED", "cannot initialize KEK", e);
        }
    }

    private ECPrivateKeyParameters loadKekPrivateKey() {
        try (FileInputStream input = new FileInputStream(keyStoreFile.toFile())) {
            KeyStore keyStore = KeyStore.getInstance("PKCS12", "BC");
            keyStore.load(input, password);
            KeyStore.PrivateKeyEntry entry = (KeyStore.PrivateKeyEntry) keyStore.getEntry(
                    KEK_ALIAS, new KeyStore.PasswordProtection(password));
            java.security.interfaces.ECPrivateKey jcePrivateKey =
                    (java.security.interfaces.ECPrivateKey) entry.getPrivateKey();
            return new ECPrivateKeyParameters(jcePrivateKey.getS(), SM2_DOMAIN);
        } catch (Exception e) {
            throw new KeyStateException("KEK_LOAD_FAILED", "cannot load KEK", e);
        }
    }

    private static ECPublicKeyParameters derivePublic(ECPrivateKeyParameters privateKey) {
        return new ECPublicKeyParameters(
                SM2_DOMAIN.getG().multiply(privateKey.getD()).normalize(), SM2_DOMAIN);
    }

    private static ECDomainParameters sm2Domain() {
        var parameters = org.bouncycastle.crypto.ec.CustomNamedCurves.getByName("sm2p256v1");
        return new ECDomainParameters(parameters.getCurve(), parameters.getG(),
                parameters.getN(), parameters.getH());
    }
}
```

`CryptoService.java`：

```java
package com.example.km;

import org.bouncycastle.jce.provider.BouncyCastleProvider;

import javax.crypto.Cipher;
import javax.crypto.spec.GCMParameterSpec;
import javax.crypto.spec.SecretKeySpec;
import java.security.SecureRandom;
import java.security.Security;
import java.util.Base64;

public class CryptoService {

    private static final int IV_LENGTH = 12;
    private static final int TAG_BITS = 128;

    private final KeyService keyService;
    private final KeyMaterialStore materialStore;
    private final SecureRandom random = new SecureRandom();

    static {
        Security.addProvider(new BouncyCastleProvider());
    }

    public CryptoService(KeyService keyService, KeyMaterialStore materialStore) {
        this.keyService = keyService;
        this.materialStore = materialStore;
    }

    public CipherMessage encrypt(String logicalKeyId, byte[] plaintext) {
        KeyVersion version = keyService.currentVersion(logicalKeyId);
        if (!version.state().canEncrypt()) {
            throw new KeyStateException("KEY_NOT_USABLE",
                    "version " + version.id() + " state=" + version.state());
        }
        byte[] keyMaterial = materialStore.load(version.id());
        byte[] iv = new byte[IV_LENGTH];
        random.nextBytes(iv);

        try {
            Cipher cipher = Cipher.getInstance("SM4/GCM/NoPadding", "BC");
            cipher.init(Cipher.ENCRYPT_MODE,
                    new SecretKeySpec(keyMaterial, "SM4"), new GCMParameterSpec(TAG_BITS, iv));
            byte[] sealed = cipher.doFinal(plaintext);
            return new CipherMessage(version.id(),
                    Base64.getEncoder().encodeToString(iv),
                    Base64.getEncoder().encodeToString(sealed));
        } catch (Exception e) {
            throw new KeyStateException("ENCRYPT_FAILED", "version " + version.id(), e);
        }
    }

    public byte[] decrypt(CipherMessage message) {
        KeyVersion version = keyService.version(message.keyVersionId);
        if (!version.state().canDecrypt()) {
            throw new KeyStateException("KEY_NOT_USABLE",
                    "version " + version.id() + " state=" + version.state());
        }
        byte[] keyMaterial = materialStore.load(version.id());
        byte[] iv = Base64.getDecoder().decode(message.iv);
        byte[] sealed = Base64.getDecoder().decode(message.ciphertext);

        try {
            Cipher cipher = Cipher.getInstance("SM4/GCM/NoPadding", "BC");
            cipher.init(Cipher.DECRYPT_MODE,
                    new SecretKeySpec(keyMaterial, "SM4"), new GCMParameterSpec(TAG_BITS, iv));
            return cipher.doFinal(sealed);
        } catch (Exception e) {
            throw new KeyStateException("DECRYPT_FAILED", "version " + version.id(), e);
        }
    }
}
```

```java
package com.example.km;

import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardOpenOption;
import java.time.Instant;

public class AuditLogger {

    private final Path file;

    public AuditLogger(Path file) {
        this.file = file;
    }

    public synchronized void append(String actor, String action,
                                    String versionId, String result) {
        String line = String.join("|", Instant.now().toString(), actor,
                action, versionId == null ? "-" : versionId, result);
        try {
            Files.createDirectories(file.getParent());
            Files.writeString(file, line + System.lineSeparator(), StandardCharsets.UTF_8,
                    StandardOpenOption.CREATE, StandardOpenOption.WRITE,
                    StandardOpenOption.APPEND);
        } catch (IOException e) {
            throw new IllegalStateException("cannot write audit log", e);
        }
    }
}
```

审计只记元数据（时间、主体、动作、对象、结果），**不记密钥材料或明文**；生产环境账号独立、必要时对日志再签名。

### 5. 密钥服务

`KeyService.java`：

```java
package com.example.km;

import java.security.SecureRandom;
import java.time.Instant;
import java.util.Map;
import java.util.Optional;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.atomic.AtomicInteger;

public class KeyService {

    private final KeyMaterialStore materialStore;
    private final AuditLogger auditLogger;
    private final Map<String, KeyVersion> versions = new ConcurrentHashMap<>();
    private final Map<String, String> current = new ConcurrentHashMap<>();
    private final AtomicInteger sequence = new AtomicInteger();

    public KeyService(KeyMaterialStore materialStore, AuditLogger auditLogger) {
        this.materialStore = materialStore;
        this.auditLogger = auditLogger;
    }

    public KeyVersion create(String logicalKeyId, String actor) {
        byte[] material = new byte[KeyAlgorithm.SM4_128.keyLength()];
        new SecureRandom().nextBytes(material);
        String versionId = logicalKeyId + "-v" + String.format("%03d",
                sequence.incrementAndGet());
        materialStore.save(versionId, material);
        KeyVersion version = new KeyVersion(versionId, logicalKeyId,
                KeyAlgorithm.SM4_128, KeyState.GENERATED, Instant.now());
        versions.put(versionId, version);
        auditLogger.append(actor, "CREATE", versionId, "OK");
        return version;
    }

    public KeyVersion activate(String versionId, String actor) {
        KeyVersion version = required(versionId);
        if (version.state() != KeyState.GENERATED) {
            throw new KeyStateException("INVALID_STATE",
                    versionId + " state=" + version.state());
        }
        version.setState(KeyState.ACTIVE);
        current.put(version.keyId(), versionId);
        auditLogger.append(actor, "ACTIVATE", versionId, "OK");
        return version;
    }

    public KeyVersion rotate(String logicalKeyId, String actor) {
        String oldVersionId = current.get(logicalKeyId);
        if (oldVersionId != null) {
            KeyVersion oldVersion = required(oldVersionId);
            oldVersion.setState(KeyState.DEPRECATED);
            auditLogger.append(actor, "DEPRECATE", oldVersionId, "OK");
        }
        KeyVersion newVersion = create(logicalKeyId, actor);
        return activate(newVersion.id(), actor);
    }

    public KeyVersion revoke(String versionId, String actor) {
        KeyVersion version = required(versionId);
        version.setState(KeyState.REVOKED);
        auditLogger.append(actor, "REVOKE", versionId, "OK");
        return version;
    }

    public KeyVersion archive(String versionId, String actor) {
        KeyVersion version = required(versionId);
        version.setState(KeyState.ARCHIVED);
        auditLogger.append(actor, "ARCHIVE", versionId, "OK");
        return version;
    }

    public KeyVersion currentVersion(String logicalKeyId) {
        return Optional.ofNullable(current.get(logicalKeyId))
                .map(this::required)
                .orElseThrow(() -> new KeyStateException("NO_ACTIVE_KEY", logicalKeyId));
    }

    public KeyVersion version(String versionId) {
        return required(versionId);
    }

    private KeyVersion required(String versionId) {
        KeyVersion version = versions.get(versionId);
        if (version == null) {
            throw new KeyStateException("VERSION_NOT_FOUND", versionId);
        }
        return version;
    }
}
```

### 6. 演示 main

`KeyManagerDemo.java`：

```java
package com.example.km;

import java.nio.charset.StandardCharsets;
import java.nio.file.Path;
import java.util.Arrays;

public class KeyManagerDemo {

    public static void main(String[] args) {
        String password = System.getenv("KM_KEYSTORE_PASSWORD");
        String auditPath = System.getenv("KM_AUDIT_LOG");
        if (password == null || auditPath == null) {
            throw new IllegalStateException(
                    "请先设置环境变量 KM_KEYSTORE_PASSWORD 和 KM_AUDIT_LOG");
        }

        KeyMaterialStore materialStore = new Pkcs12KeyMaterialStore(
                Path.of("target/km/keys.p12"), password.toCharArray());
        AuditLogger auditLogger = new AuditLogger(Path.of(auditPath));
        KeyService keyService = new KeyService(materialStore, auditLogger);
        CryptoService cryptoService = new CryptoService(keyService, materialStore);

        String logicalKeyId = "order-data-key";
        keyService.activate(keyService.create(logicalKeyId, "ops-admin").id(), "ops-admin");

        byte[] first = "first payment record".getBytes(StandardCharsets.UTF_8);
        CipherMessage firstMessage = cryptoService.encrypt(logicalKeyId, first);
        System.out.println("first sealed by " + firstMessage.keyVersionId);

        keyService.rotate(logicalKeyId, "ops-admin");

        byte[] second = "second payment record".getBytes(StandardCharsets.UTF_8);
        CipherMessage secondMessage = cryptoService.encrypt(logicalKeyId, second);
        System.out.println("second sealed by " + secondMessage.keyVersionId);

        System.out.println("old ciphertext still readable: "
                + Arrays.equals(first, cryptoService.decrypt(firstMessage)));
        System.out.println("new ciphertext readable: "
                + Arrays.equals(second, cryptoService.decrypt(secondMessage)));

        keyService.revoke(firstMessage.keyVersionId, "security-oncall");
        try {
            cryptoService.decrypt(firstMessage);
            System.out.println("DANGER: revoked key still works!");
        } catch (KeyStateException e) {
            System.out.println("revoked key rejected: " + e.code());
        }
    }
}
```

### 7. 轮换演练测试

`KeyServiceRotationTest.java`：

```java
package com.example.km;

import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.io.TempDir;

import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;

import static org.junit.jupiter.api.Assertions.assertEquals;
import static org.junit.jupiter.api.Assertions.assertFalse;
import static org.junit.jupiter.api.Assertions.assertThrows;
import static org.junit.jupiter.api.Assertions.assertTrue;

class KeyServiceRotationTest {

    private static final String LOGICAL_KEY_ID = "tenant-a-data-key";

    @TempDir
    Path tempDir;

    private KeyService keyService;
    private CryptoService cryptoService;
    private Path auditFile;

    @BeforeEach
    void setUp() {
        char[] password = "test-only-password-not-for-production".toCharArray();
        KeyMaterialStore materialStore = new Pkcs12KeyMaterialStore(
                tempDir.resolve("keys.p12"), password);
        auditFile = tempDir.resolve("audit.log");
        AuditLogger auditLogger = new AuditLogger(auditFile);
        keyService = new KeyService(materialStore, auditLogger);
        cryptoService = new CryptoService(keyService, materialStore);
    }

    @Test
    void rotationKeepsOldCiphertextReadable() {
        keyService.activate(keyService.create(LOGICAL_KEY_ID, "tester").id(), "tester");
        byte[] first = "payload-v1".getBytes(StandardCharsets.UTF_8);
        CipherMessage firstMessage = cryptoService.encrypt(LOGICAL_KEY_ID, first);
        assertEquals(firstMessage.keyVersionId, keyService.currentVersion(LOGICAL_KEY_ID).id());

        KeyVersion version2 = keyService.rotate(LOGICAL_KEY_ID, "tester");
        assertEquals(KeyState.ACTIVE, version2.state());
        assertEquals(KeyState.DEPRECATED, keyService.version(firstMessage.keyVersionId).state());

        byte[] second = "payload-v2".getBytes(StandardCharsets.UTF_8);
        CipherMessage secondMessage = cryptoService.encrypt(LOGICAL_KEY_ID, second);
        assertEquals(version2.id(), secondMessage.keyVersionId);

        assertTrue(new String(cryptoService.decrypt(firstMessage), StandardCharsets.UTF_8)
                .equals("payload-v1"));
        assertTrue(new String(cryptoService.decrypt(secondMessage), StandardCharsets.UTF_8)
                .equals("payload-v2"));
    }

    @Test
    void revokeBlocksOldKeyImmediately() {
        keyService.activate(keyService.create(LOGICAL_KEY_ID, "tester").id(), "tester");
        CipherMessage message = cryptoService.encrypt(LOGICAL_KEY_ID,
                "secret".getBytes(StandardCharsets.UTF_8));

        keyService.revoke(message.keyVersionId, "oncall");
        KeyStateException exception = assertThrows(KeyStateException.class,
                () -> cryptoService.decrypt(message));
        assertEquals("KEY_NOT_USABLE", exception.code());
    }

    @Test
    void auditLogIsAppendOnlyWithAllEvents() throws Exception {
        keyService.activate(keyService.create(LOGICAL_KEY_ID, "tester").id(), "tester");
        keyService.rotate(LOGICAL_KEY_ID, "tester");
        List<String> lines = Files.readAllLines(auditFile);
        assertTrue(lines.stream().anyMatch(line -> line.contains("|CREATE|")));
        assertTrue(lines.stream().anyMatch(line -> line.contains("|ACTIVATE|")));
        assertTrue(lines.stream().anyMatch(line -> line.contains("|DEPRECATE|")));
        assertFalse(lines.stream().anyMatch(line -> line.contains("SM4")
                && line.split("\\|").length > 5));
    }
}
```

## 验收标准

- 轮换后：新数据用新版本加密；旧密文由 `DEPRECATED` 旧密钥解密成功。
- `revoke` 后：对应版本解密立即被拒，返回 `KEY_NOT_USABLE`。
- 审计日志追加写，包含 CREATE / ACTIVATE / DEPRECATE / REVOKE 事件，且不含密钥材料。
- 生产代码路径中无硬编码口令：口令仅来自环境变量；SM2 KEK 在 PKCS#12 内、DEK 以信封落地。
- `KeyMaterialStore` 可在不改业务代码的前提下，从 PKCS#12 实现替换为 KMS 实现。

## 扩展思考

- 生产环境版本元数据应入库（事务化），材料存 KMS/HSM；本原型用内存 Map 仅作演示，重启后需从库重建。
- 真正的信封模式：这里直接用 SM4 主密钥加密数据；工程上应「KEK 包 DEK、DEK 碰数据」，轮换 KEK 时只需 rewrap DEK，不必重加密正文。
- 重叠期要覆盖在途消息、缓存、异地备份；旧密钥从 `DEPRECATED` 到 `ARCHIVED` 再到 `DESTROYED` 应有明确时间与审批。
- 口令使用后应 `Arrays.fill(password, '\0')`，减少驻留时间；审计账号与业务账号分离。
- 可增加自动轮换：按周期调度 `rotate`，并在轮换后发监控指标（新旧版本加解密计数）。

## 失败排查

| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 启动抛「请先设置环境变量」 | 未注入口令 / 审计路径 | 先 `export` 再运行；IDEA 在运行配置的 Environment 中设置 |
| PKCS12 读取失败 | 口令变更 / 文件损坏 | 用独立测试目录；密钥库文件不可手工编辑 |
| 旧密文解不开 | 版本号未随密文保存 | 确认 `CipherMessage.keyVersionId` 已持久化 |
| 吊销后仍能解密 | 用了缓存的明文 DEK | 每次解密按版本现取，避免长期缓存密钥材料 |
| 测试间互相污染 | 共用目录 | 使用 `@TempDir`，每用例独立 keystore |
| 找不到 SM4/GCM/NoPadding | BC 未注册 | 确认 `CryptoService` 静态块执行、依赖存在 |
| `PKCS12 does not support non-PrivateKeys` | 试图把 SM4 直接当 SecretKeyEntry | 改为 SM2 KEK 入 PKCS12、DEK 信封落地 |
| `org.bouncycastle.cert 不存在` | 缺 bcpkix | 增加 `bcpkix-jdk18on` 依赖 |
