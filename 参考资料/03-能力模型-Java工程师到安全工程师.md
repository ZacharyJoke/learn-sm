# 能力模型：从 Java 工程师到安全工程师

> 五个等级：L1 认知 → L2 会用 → L3 能设计 → L4 主导改造迎检 → L5 体系化赋能。
> 每级给出「知识 / 技能 / 行为证据 / 产出」四要素；证据比头衔更可信，晋级以可验证产出为准。

## 一、五级总览

| 级别 | 一句话定位 | 典型岗位场景 |
|------|------------|--------------|
| L1 认知 | 听得懂、不犯错 | 评审中能识别「自研算法、ECB、裸存口令」等明显问题 |
| L2 会用 | 能用标准库正确实现 | 独立交付 SM3/SM2/SM4 工具类并通过标准向量 |
| L3 能设计 | 能设计单系统密码方案 | 负责一个业务系统的算法选型、密钥分层与协议落地 |
| L4 主导改造迎检 | 能主导存量国密改造与密评 | 牵头盘点、改造、双栈过渡、证书体系，对密评结论负责 |
| L5 体系化赋能 | 建设组织级密码能力 | 平台化、规范体系、人才培养、前沿演进（含 PQC 过渡） |

## 二、各级细则

### L1 认知层

- 知识：知道对称/非对称/杂凑三族与 SM1~SM9、ZUC 的定位；知道标准号（GB/T 32918、32905、32907、GM/T 0003/0004/0002 等）；知道 SM1/SM7 不公开；知道等保、密评、GB/T 39786 的存在。
- 技能：看懂项目中 BC 调用；区分编码（Hex/Base64）与加密；能判断「这是不是在自研密码」。
- 行为证据：评审或代码中主动指出 ECB 加密、明文密钥、SM3 存口令等问题并说明后果。
- 产出：国密术语卡片；七算法对照表笔记；至少 3 次评审问题记录。

### L2 会用层

- 知识：理解 SM3 压缩流程与输出长度；SM2 公私钥、ZA 与用户 ID 的作用、C1C3C2 结构；SM4 轮次与模式差异；知道标准向量与 OID。
- 技能：BC 1.84 下实现 SM3/HMAC-SM3、SM3withSM2 签名验签、SM2 加解密、SM4 CBC/GCM；DER 与 raw 互转；SecureRandom 正确使用；独立排查常见报错。
- 行为证据：所有实现先用标准向量对拍；能复现并解释「ID 不一致验签失败」「IV 固定」等实验。
- 产出：`SM3Utils/SM2Utils/SM4Utils` 工具类及单测；报错排查手册；2 个可演示 demo。

### L3 能设计层

- 知识：掌握认证加密与模式选型；密钥生命周期与 DEK/KEK 分层；信封加密；TLCP/双证书；随机数熵源；性能量级；常见协议攻击面（重放、篡改、 downgrade）。
- 技能：输出单系统密码设计：算法/模式/IV-nonce 规则/编码格式/密文结构约定/密钥来源/轮换方案；设计接口防重放（时间戳+nonce+签名，而非只靠哈希）；做容量评估与 JMH 基线；定义跨语言互通契约。
- 行为证据：设计评审中能讲出每个选择的威胁与取舍；方案含「禁止事项」；上线前给出验证清单。
- 产出：系统密码设计说明书；密钥流转图；互通契约文档；性能基线与应急预案。

### L4 主导改造迎检层

- 知识：熟悉 GB/T 39786、GM/T 0054 应用要求与密评流程；证书体系与 GM/T 0015/0024；SDF/HSM/KMS 对接；双栈与灰度策略；供应链与跨团队协作机制。
- 技能：主导密码资产盘点与分级；制定改造路线图与里程碑；处理双证书、证书过期、时钟同步、nonce 分片部署等架构难题；推动应用、运维、证书厂商多方协同；组织整改并闭环密评问题。
- 行为证据：以项目负责人身份完成至少一次存量改造并通过评估；风险决策有记录、可追溯；能向管理层汇报合规差距与投入产出。
- 产出：国密改造方案（套用 `templates/02-国密改造方案模板.md`）；资产台账；密评问题闭环台账；复盘与回退预案。

### L5 体系化赋能层

- 知识：具备攻防双视角（密码误用、协议缺陷、密钥泄露后果链）；理解云原生密码服务、HSM 即服务、PQC 迁移框架；理解合规体系与组织治理；能判断标准演进方向而不臆测（国密 PQC 以官方发布为准）。
- 技能：建设密码中台/统一组件（Starter、网关、KMS 封装）；制定企业密码规范与红线；设计密评常态化与自动化度量；培养 L1~L4 人才梯队；建立事件响应与密钥应急体系。
- 行为证据：组件被多业务线复用且事故率下降；规范在真实项目中被执行而非停留在文档；组织过跨部门密码实战演练。
- 产出：企业密码服务平台；密码规范白皮书；培训体系与认证机制；年度密码风险地图。

## 三、晋级 Checklist

### L1 → L2

- [ ] 不看教程独立写出 SM3/SM2/SM4 六类常用操作
- [ ] 全部通过官方标准向量（空串、abc、SM4 ECB 向量）
- [ ] 能解释默认用户 ID 与 04 前缀，做过 DER/raw 互转
- [ ] 独立解决过至少 5 个报错并记录「现象-原因-处理」

### L2 → L3

- [ ] 独立完成过至少 1 个真实业务的密码模块设计并上线
- [ ] 能写出完整密钥流转图（生成/分发/存储/使用/轮换/销毁）
- [ ] 做过性能基准，数据能支撑模式选型
- [ ] 完成过一次跨语言/跨系统互通联调并留下契约文档
- [ ] 设计的接口含防重放、防篡改、防降级的具体机制

### L3 → L4

- [ ] 主导过存量系统密码资产盘点，产出分级台账
- [ ] 主导过一次完整国密改造（含双栈/灰度/回退）
- [ ] 对接过至少一种企业级密钥设施（KMS/HSM/SDF）
- [ ] 完整经历一次密评或等保密码相关检查，推动问题闭环
- [ ] 能独立处理证书体系、时钟、nonce 分片等跨团队难题

### L4 → L5

- [ ] 建成被 3 个以上系统复用的统一密码组件/服务
- [ ] 制定的规范在项目中可审计、可追责、有度量
- [ ] 培养出至少 2 名 L3 工程师（有作品为证）
- [ ] 组织过密钥泄露等实战应急演练并完成复盘
- [ ] 对 PQC 过渡等前沿议题有路线研究，且严格区分事实与推测
