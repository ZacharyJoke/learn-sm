# 安全审计检查清单（国密）

> 用法：逐条核对，在「结果」列填写：符合 / 不符合 / 不适用。不符合项须登记整改责任人与期限，截图或命令输出作为证据留存。
> 检查对象：【系统名称】；检查日期：【YYYY-MM-DD】；检查人：【】；陪同人：【】。

## 一、算法使用

| 序号 | 检查项 | 判定标准 | 结果 |
|------|--------|----------|------|
| 1.1 | 对称算法合规 | 使用 SM4（或经批准的密码产品 SM1/SM7），无 DES/3DES/自研算法 | |
| 1.2 | 非对称算法合规 | 签名/加密使用 SM2（曲线 sm2p256v1），关键业务无 SHA1withRSA 等弱套件 | |
| 1.3 | 杂凑算法合规 | 使用 SM3；无 MD5/SHA-1 用于安全目的 | |
| 1.4 | 分组模式 | 业务数据不使用 ECB；使用 CBC（随机 IV）或 GCM | |
| 1.5 | 认证加密 | 高风险通道优先 GCM 或「加密+独立 HMAC」规范组合 | |
| 1.6 | 口令存储 | 加盐慢哈希（PBKDF2/Argon2/bcrypt 等），未使用 SM3 裸哈希 | |
| 1.7 | 标准向量验证 | SM3 空串/abc、SM4 ECB 向量测试通过 | |
| 1.8 | 算法版本 | BouncyCastle 等库为受支持版本（建议 bcprov 1.84），无已知漏洞版本 | |

## 二、密钥管理

| 序号 | 检查项 | 判定标准 | 结果 |
|------|--------|----------|------|
| 2.1 | 密钥分级 | 建立 DEK/KEK 等分级台账，职责明确 | |
| 2.2 | 密钥来源 | 密钥由 KMS/HSM/密码机或批准随机流程生成，无人为设定 | |
| 2.3 | 硬编码检查 | 代码、配置、镜像、前端包中无明文密钥（SAST 扫描零命中） | |
| 2.4 | 私钥保护 | 高价值私钥在 HSM/SDF 内运算或加密存储，可导出私钥有审批 | |
| 2.5 | 信封加密 | DEK 经 KEK/KMS 封装存储，应用不长期持有主密钥 | |
| 2.6 | 轮换机制 | 轮换周期、重加密批次与记录齐全，到期提醒有效 | |
| 2.7 | 密钥备份恢复 | 备份加密/分片保管，有恢复演练记录 | |
| 2.8 | 多租户隔离 | 租户间 DEK/授权相互独立 | |

## 三、随机数

| 序号 | 检查项 | 判定标准 | 结果 |
|------|--------|----------|------|
| 3.1 | 随机源 | 密码场景使用 `SecureRandom` 或密码机随机数接口，无 `Random`/时间戳种子 | |
| 3.2 | IV/nonce 生成 | CBC IV 随机不可预测；GCM nonce 同密钥下唯一（建议随机 12 字节） | |
| 3.3 | nonce 分片安全 | 多实例部署无 nonce 冲突风险，计数器重启不回退 | |
| 3.4 | 熵与阻塞 | 容器/主机熵源充足；启动阻塞问题有明确配置与验证 | |

## 四、编码与数据格式

| 序号 | 检查项 | 判定标准 | 结果 |
|------|--------|----------|------|
| 4.1 | 编码统一 | Hex/Base64 标准统一；比较与签名均在字节层进行 | |
| 4.2 | 字符集 | 全链路 UTF-8，无平台默认字符集依赖 | |
| 4.3 | 公钥格式 | 未压缩点含 04 前缀，坐标 32 字节定长 | |
| 4.4 | SM2 密文顺序 | 使用 C1C3C2（GM/T 0009）；与旧系统互通有转换记录 | |
| 4.5 | 签名格式 | DER/raw 经契约约定，互转有测试 | |
| 4.6 | GCM 布局 | tag 位置与 AAD 拼接规则文档化并与对端一致 | |
| 4.7 | 字节序 | 整数/长度字段统一大端，定长补零 | |

## 五、协议与接口

| 序号 | 检查项 | 判定标准 | 结果 |
|------|--------|----------|------|
| 5.1 | 传输加密 | 管理面、业务面、外部接口均启用合规加密通道 | |
| 5.2 | 国密协议 | VPN/网关使用 GM/T 0024 套件或批准方案 | |
| 5.3 | 双向认证 | 高安全链路启用双证书/双向 mTLS | |
| 5.4 | 防重放 | 接口具备时间戳+nonce 去重+签名机制 | |
| 5.5 | 防降级 | 协议版本协商防 downgrade，回退路径需认证且限时 | |
| 5.6 | 会话管理 | 会话密钥独立、按时失效，无长期固定预共享密钥 | |
| 5.7 | 第三方对接 | 外发接口密码契约明确，密钥分发不走明文渠道 | |
